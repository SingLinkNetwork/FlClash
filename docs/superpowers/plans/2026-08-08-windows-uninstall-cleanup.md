# Windows 卸載與資料清理實作計畫

## 1. 建立失敗驗證

- 新增安裝器檢查，要求開始選單捷徑、清理參數、四個資料路徑與 Windows CI 卸載測試存在。
- 在目前版本執行檢查，確認它先因缺少清理流程而失敗。

## 2. 實作安全清理流程

- 在 Inno Setup 卸載初始化階段停止相關程序。
- 互動卸載時詢問是否清理；非互動 CI 以明確參數啟用清理。
- 只刪除已知的 FlClash 資料資料夾，保留預設卸載的資料保留行為。

## 3. 接入 Windows CI

- 建置安裝器後，確認開始選單捷徑存在。
- 安裝測試包，建立四個測試資料位置，使用清理參數卸載。
- 確認安裝目錄、捷徑與測試資料均已清除。

## 4. 驗證與交付

- 執行本機靜態檢查、Dart 測試、分析與 Go 檢查。
- 推送後等待同一個提交的完整跨平台 CI，所有檢查通過後才建立下游 issue 並關閉。
